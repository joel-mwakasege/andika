A modular companion extension for Andika that transforms distraction-free screenplay drafts into production-ready script breakdowns, cast trackers, and shooting schedule stripboards.

== Description ==

Andika Movie Production expands the Andika distraction-free writing studio for filmmakers, screenwriters, directors, and 1st ADs:

* **Live Scene Breakdown:** Automatically parses standard sluglines (e.g. `INT. DINER - DAY`, `EXT. STREET - NIGHT`) and extracts Scene Number, Setting, Location, and Time of Day.
* **1/8th Page Calculator:** Converts screenplay line counts into industry-standard 1/8th page measurements and estimates running times.
* **Cast & Character Tracker:** Identifies speaking roles per scene, aggregates total cues, and tracks scene appearances for Day-out-of-Days scheduling.
* **Production Elements & Props:** Scans action lines for vehicles, weapons, key props, and sound effects.
* **Interactive Stripboard:** Color-coded strips (Yellow for EXT. DAY, Blue for INT. NIGHT, White for INT. DAY, Green for EXT. NIGHT) with instant jump-to-scene in the editor.
* **Export & Print:** One-click Print Breakdown Sheet and Export Stripboard CSV for production scheduling tools.

== Installation ==

1. Upload the `andika-movie-production` folder to `/wp-content/plugins/`.
2. Activate either via WordPress Plugins screen or through Andika's Settings -> Extensions panel.
